1. PROJECT OVERVIEW
================================================================================
Gym Habit is a comprehensive web application for managing gym partnerships,
leads, and subscription requests. It features:
- Public-facing gym discovery and subscription request form
- Admin panel for managing gyms, partners, leads, and users
- Role-based access control (Admin, Facilitator)
- JWT-based authentication
- MongoDB database with Motor (async driver)
- FastAPI backend with async/await
- Vanilla JavaScript frontend

================================================================================
2. TECHNOLOGY STACK
================================================================================
Backend:
- FastAPI 0.104.1 (Python async web framework)
- Uvicorn 0.24.0 (ASGI server)
- Motor 3.7.1 (Async MongoDB driver)
- PyMongo 4.15.5
- Python-Jose 3.5.0 (JWT tokens)
- Passlib 1.7.4 with Bcrypt (Password hashing)
- Pydantic 2.5.0 (Data validation)

Frontend:
- Vanilla JavaScript (ES6+)
- HTML5
- CSS3 with custom properties
- No framework dependencies

Database:
- MongoDB Atlas (Cloud hosted)
- Collections: gyms, partners, leads, users

Deployment:
- Render.com (Web service)
- GitHub integration for CI/CD

9. API ENDPOINTS
================================================================================

PUBLIC ENDPOINTS (No Authentication):
--------------------------------------
GET  /api/gyms?pincode=110001&partner=Gold's Gym&limit=20&offset=0
     - Get list of active gyms with filters
     - Returns: {gyms: [...], total: N}

GET  /api/gyms/{gym_id}
     - Get single gym details with subscription plans
     - Returns: {gym data with subscription_plans array}

POST /api/subscription/request
     - Submit subscription request/lead
     - Body: SubscriptionRequest (full_name, email, phone, gym_id, plan)
     - Returns: {success: true, message: "...", lead_id: "GYM_20251215_0001"}

GET  /api/partners
     - Get list of all partners
     - Returns: {partners: [...], total: N}

AUTHENTICATION ENDPOINTS:
-------------------------
POST /api/auth/login
     - Login with email and password
     - Body: {email: "...", password: "..."}
     - Returns: {access_token: "...", user: {...}}

ADMIN/FACILITATOR ENDPOINTS (Requires JWT):
--------------------------------------------
LEADS:
GET    /api/admin/leads?status=New&payment_status=Pending&search=john
       - Get filtered leads with pagination
       - Returns: {leads: [...], total: N}

GET    /api/admin/leads/{lead_id}
       - Get single lead details
       - Returns: {lead data with audit trail}

PATCH  /api/admin/leads/{lead_id}/status
       - Update lead status
       - Body: status=Contacted
       - Auto-assigns lead to current user

PATCH  /api/admin/leads/{lead_id}/payment
       - Update payment status
       - Body: payment_status=Paid&payment_amount=5000
       - Auto-assigns lead to current user

PATCH  /api/admin/leads/{lead_id}/plan
       - Update subscription plan
       - Body: plan=3-month
       - Auto-assigns lead to current user

POST   /api/admin/leads/{lead_id}/comment
       - Add comment to lead
       - Body: comment=Customer interested
       - Auto-assigns lead to current user

GET    /api/admin/leads/export
       - Export all leads to CSV
       - Returns: CSV file download

GYMS (Admin Only):
GET    /api/admin/gyms?partner=Gold's Gym&search=Delhi
       - Get all gyms (including inactive)
       - Returns: {gyms: [...], total: N}

POST   /api/admin/gyms
       - Create new gym
       - Body: multipart/form-data (all gym fields + icon)
       - Returns: {gym_id: N}

PUT    /api/admin/gyms/{gym_id}
       - Update existing gym
       - Body: multipart/form-data (all gym fields + icon)
       - Returns: {message: "..."}

DELETE /api/admin/gyms/{gym_id}
       - Soft delete gym (mark inactive)
       - Returns: {message: "..."}

POST   /api/admin/gyms/upload-csv
       - Bulk upload gyms via CSV
       - Body: multipart/form-data (file)
       - Returns: {created: N, failed: N, errors: [...]}

PARTNERS (Admin Only):
GET    /api/admin/partners
       - Get all partners with gym counts
       - Returns: {partners: [...], total: N}

POST   /api/admin/partners
       - Create new partner
       - Body: {name: "...", description: "...", icon: "..."}
       - Returns: {message: "..."}

PUT    /api/admin/partners/{partner_name}
       - Update/upsert partner
       - Body: {name: "...", description: "...", icon: "..."}
       - Cascades name changes to gyms
       - Returns: {message: "..."}

DELETE /api/admin/partners/{partner_name}
       - Delete partner and associated gyms
       - Returns: {message: "..."}

USERS (Admin Only):
GET    /api/admin/users
       - Get all users
       - Returns: {users: [...]}

POST   /api/admin/users
       - Create new user
       - Body: multipart/form-data (email, name, password, role)
       - Returns: {user_id: "..."}

DELETE /api/admin/users/{user_id}
       - Deactivate user (only facilitators, not admins)
       - Returns: {message: "..."}

PUT    /api/admin/users/{user_id}/activate
       - Activate inactive user
       - Returns: {message: "..."}
