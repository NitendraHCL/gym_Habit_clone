CSV Format Requirements:

Your CSV file should have the following columns:

gym_name,partner_name,address,city,state,pincode,latitude,longitude,amenities,subscription_amount,plan_1m,plan_3m,plan_6m,plan_12m

Required columns: gym_name through subscription_amount
Amenities: Pipe-separated (e.g., "Cardio|Weights|Yoga")
subscription_amount: Monthly base price in ₹ (e.g., 2499). Defaults to 1499 if omitted.
Custom Plans (Optional): plan_1m, plan_3m, plan_6m, plan_12m - Total price for 1, 3, 6, and 12 month plans. If omitted, auto-calculated from subscription_amount.
